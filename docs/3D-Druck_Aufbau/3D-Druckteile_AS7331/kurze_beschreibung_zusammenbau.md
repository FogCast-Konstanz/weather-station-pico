# Kurze Beschreibung nach dem Drucken der (stl) Teile

1. Den UV-Sensor (AS7331) soll auf die *Halterung_fuer_UV-Sensor.STL-Körper* bei der vorgesehenen Tasche platziert und mit Schrauben fixiert werden.
2. *Halterung_fuer_UV-Sensor.STL-Körper* soll nun in das Alu-Gussgehäuse platziert werden. Dabei muss die Verkabelung (Qwiic-Kabel) durch die Tasche und der Bohrung hindurch geführt werden.
3. Das Alu-Gussgehäuse soll nun in *Halterung_fuer_Aluguss-Gehaeuse-Körper* gespannt werden. Dabei muss wiederum auf die Verkabelung geachtet werden.
4. Nun kann das *Halterung_fuer_Aluguss-Gehaeuse-Körper* auf das Druckteil *Halterung_fuer_UV-Halterung-Körper* geschraubt werden. Die *Halterung_fuer_UV-Halterung-Körper* kann nun an die Holzbox an der Seite an den vorgesehenen Bohrungen fixiert werden. Verkabelung wieder beachten.
5. Die Verkabelung kann nun in die Holzbox geführt werden.
